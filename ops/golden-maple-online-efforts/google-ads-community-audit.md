# Golden Maple Google Ads Community Audit — Bigger Projects Outside Barrie

Status: **strategy/audit asset only**. No Google Ads account changes made. This is the targeting model to apply after Yorkis approves spend/account edits.

## Audit Finding

The current draft ad model is too Barrie-centric for $50K-$150K work. Barrie is useful for volume, but the bigger-margin hardscape opportunities are more likely in estate, waterfront, slope, acreage, and newer high-equity communities around Barrie.

The account should not run one generic Simcoe campaign. It should split budget by **community quality + project complexity**.

## Core Rule

Target where the property itself creates premium scope:

- slopes and grade changes
- waterfront or lake-adjacent outdoor living
- acreage / estate lots
- larger backyards
- new builds with unfinished builder-basic yards
- high-equity family neighbourhoods
- homes where a $50K-$150K outdoor project makes sense against property value

| **Snow Valley / Anten Mills** | Larger country lots, slopes, family homes | Outdoor rooms + retaining/grade correction |

### Tier B — Good, But Needs Filtering
Run with budget filters and exact/phrase match only.

| Community | Use Case | Caution |
|---|---|---|
| **Alcona / Lefroy / Stroud** | Family backyard upgrades, patios, outdoor rooms | Some price-sensitive traffic; use $35K+ framing |
| **Oro Station / Craighurst** | Rural/estate lots, patios, walls | Lower search volume |
| **Wasaga Beach** | Cottage/beach homes, patios/decks | Distance + sand-base education required |
| **Orillia waterfront / Atherley** | Waterfront patios, older-home drainage | Filter hard for budget |
| **Collingwood / Blue Mountain edge** | High value homes, lifestyle buyers | Distance premium; only target $90K+ work |

### Tier C — Limit or Exclude Unless Search Terms Prove Value

- Downtown Barrie generic landscaper traffic
- Angus / Essa broad landscaping unless query is high-intent hardscape
- Midland/Penetang broad traffic unless waterfront/premium terms are present
- Any low-budget search containing repair, cheap, DIY, lawn, sod, or maintenance language

## Location Settings Audit Checklist

Apply these inside Google Ads:

1. **Presence only**: target people **in or regularly in** the selected locations. Do not target people merely interested in the location.
2. Turn off broad geographic expansion if enabled.
3. Separate Barrie from premium outer communities so Barrie volume does not hide poor quality.
4. Use exact and phrase match first. Avoid broad match until there is conversion data.
5. Exclude low-fit communities after search-term review, not by ego.
6. Track qualified lead, not just form submit.
7. Add lead tier into CRM/reporting so Google Ads can be judged by A/B leads.
8. Do not optimize for max conversions if the conversion is unqualified form spam. Optimize around qualified lead/imported offline conversion once available.

## Radius / Pin Targeting Model

Use pin/radius around premium pockets instead of one big Simcoe radius.

Suggested radius groups:

- Midhurst: 8-12 km
- Snow Valley: 8-12 km
- Anten Mills: 8-12 km
- Horseshoe Valley: 8-12 km
- Sugarbush: 8-12 km
- Shanty Bay: 8-12 km
- Big Bay Point / Friday Harbour: 8-12 km
- Hawkestone: 8-12 km

Avoid a single 40 km radius from Barrie. It pulls in too much mixed-intent traffic.

## Ad Copy Adjustments

### Use this budget filter
Most premium hardscape projects start around **$35K+**. Outdoor living, retaining wall, and full backyard projects commonly plan between **$50K and $150K+** depending on site conditions.

### Estate / Outdoor Living Description
Premium patios and outdoor living spaces for larger Simcoe County properties. Proper base prep, drainage planning, and a 5-year structural warranty.

### Slope / Wall Description
Sloped yard, failing wall, or drainage issue? Golden Maple builds retaining wall and hardscape systems that reclaim usable outdoor space.

## Decision

The new target is not "outside Barrie" broadly.

The target is:

**Midhurst / Springwater / Oro-Medonte / Horseshoe Valley / Shanty Bay / Innisfil waterfront / Friday Harbour / Big Bay Point**

Those communities best match $50K-$150K projects because they carry larger lots, more grade complexity, lifestyle buyers, and enough property value to justify premium outdoor construction.
